# 💰 Финансовый аналитик

Личное приложение для учёта трат и накоплений. Работает на телефоне как обычное
приложение (PWA), **полностью без интернета**. Все данные хранятся только на вашем
устройстве — никаких серверов.

- **Траты** (отдельная вкладка) — статьи расходов с лимитами на неделю / месяц / квартал / год.
- **Быстрые траты** — «облако» кнопок на главном экране: цвет — цвет статьи, чем чаще трата, тем крупнее кнопка.
- **Накопить** — копилки с целями и сроками.
- **Закрытие периода** — излишки в копилку, перерасход в отклонения / из копилки / на следующий период.
- **Доходы**, **Аналитика** (графики), **Настройки** (резервная копия, тема, день начала месяца).

## 1. Как запустить на компьютере

Нужен один раз установить **Node.js** (версия 20 или новее): <https://nodejs.org> → кнопка «LTS» → установить
как обычную программу.

Затем откройте папку проекта в терминале (в Windows: в папке нажмите правой кнопкой →
«Открыть в терминале») и выполните по очереди:

```bash
npm install
```

(скачает библиотеки, один раз, 1–3 минуты)

```bash
npm run dev
```

В терминале появится адрес вида `http://localhost:5173` — откройте его в браузере.
Чтобы остановить — в терминале нажмите `Ctrl + C`.

Совет: в браузере нажмите `F12` → значок телефона, чтобы увидеть приложение в размере смартфона.

Другие команды:

| Команда | Что делает |
|---|---|
| `npm run build` | Собирает готовую версию в папку `dist` |
| `npm run preview` | Показывает собранную версию (так можно проверить офлайн-режим) |
| `npm run icons` | Перерисовывает иконки приложения в `public/` |

> ⚠️ Проект лежит в папке OneDrive. Папка `node_modules` содержит тысячи файлов, и OneDrive
> будет долго их синхронизировать. Если компьютер «тормозит» — лучше перенести проект в папку
> вне OneDrive (например, `C:\Projects\my-money`). Код всё равно хранится в git и на GitHub.

## 2. Как опубликовать на GitHub Pages

Это нужно, чтобы открыть приложение на телефоне по ссылке и установить его. Публикуется только
**код** приложения — ваши данные туда не попадают никогда.

### Первый раз

1. Зарегистрируйтесь на <https://github.com> (бесплатно).
2. Справа вверху «+» → **New repository**. Имя, например, `my-money`. Видимость — **Public**
   (для бесплатного GitHub Pages). Остальное не трогайте → **Create repository**.
3. GitHub покажет адрес репозитория вида `https://github.com/ВАШ_ЛОГИН/my-money.git`.
   В терминале в папке проекта выполните (подставьте свой адрес):

   ```bash
   git remote add origin https://github.com/ВАШ_ЛОГИН/my-money.git
   ```

   ```bash
   git push -u origin main
   ```

   При первой отправке откроется окно входа в GitHub — войдите.
4. На странице репозитория: **Settings** → слева **Pages** → в поле **Source** выберите
   **GitHub Actions**.
5. Откройте вкладку **Actions** — там идёт сборка «Публикация на GitHub Pages» (1–2 минуты).
   Когда появится зелёная галочка, приложение доступно по адресу:

   `https://ВАШ_ЛОГИН.github.io/my-money/`

### Обновления

После любых правок достаточно:

```bash
git push
```

GitHub сам пересоберёт и опубликует новую версию. Установленное на телефоне приложение
подхватит обновление автоматически при следующем запуске с интернетом (иногда нужно
закрыть и открыть его ещё раз).

## 3. Как установить на телефон

Откройте ссылку `https://ВАШ_ЛОГИН.github.io/my-money/` на телефоне.

**Android (Chrome):** меню «⋮» справа вверху → **«Установить приложение»** (или «Добавить на
главный экран») → «Установить». На главном экране появится иконка «Финансы».

**iPhone (только Safari!):** кнопка «Поделиться» (квадрат со стрелкой) внизу → прокрутите →
**«На экран «Домой»»** → «Добавить».

После установки приложение работает без интернета. Интернет нужен только чтобы получить
новую версию.

## 4. Резервная копия данных — обязательно!

Данные лежат **только в памяти телефона**, внутри приложения. Если удалить приложение,
очистить данные браузера или потерять телефон — данные пропадут. Единственная защита —
резервная копия.

**Сохранить копию:** Настройки → **«Сохранить копию (JSON)»**.
- На телефоне откроется меню «Поделиться» — отправьте файл себе в Telegram «Избранное»,
  на почту, в Google Диск / iCloud / Яндекс Диск.
- На компьютере файл `finance-backup-ГГГГ-ММ-ДД.json` скачается в «Загрузки».

Делайте копию регулярно, например раз в неделю и после закрытия месяца.

**Восстановить:** Настройки → **«Восстановить из файла»** → выберите файл копии. Приложение
покажет, что в файле, и попросит подтвердить: **текущие данные на устройстве будут заменены**.

**Перенос на новый телефон:** сохраните копию на старом → установите приложение на новом →
восстановите из файла.

> На iPhone Safari может удалить данные сайта, если приложением не пользоваться несколько
> недель и оно **не установлено** на экран «Домой». Установленное приложение защищено лучше,
> но копию всё равно делайте.

## Устройство проекта (для разработки)

Стек: Vite + React + TypeScript + Tailwind CSS 4, IndexedDB через Dexie, PWA через
vite-plugin-pwa, графики — Recharts.

```
src/
  db/          данные
    types.ts     модели (Category, Expense, Jar, …)
    db.ts        схема базы IndexedDB (Dexie)
    actions.ts   все изменения данных + закрытие периода
    backup.ts    экспорт / импорт / сброс
    demo.ts      демонстрационные данные
  lib/         чистые функции без интерфейса
    dates.ts     периоды (неделя/месяц/квартал/год), форматы дат
    calc.ts      вычисляемые значения (потрачено, остаток, накоплено…)
    format.ts    форматирование денег «12 345 ₽», разбор ввода
    phrases.ts   фразы для закрытия периода
  hooks/       useData (живые выборки из базы), useRoute (навигация)
  components/  плашки, формы, окна-листы; ui/ — базовые элементы
  screens/     экраны: Home, Spend, CategoryDetail, Save, JarDetail, Income, Analytics, Settings
```

Принципы:
- Вычисляемые значения (потрачено, остаток, накоплено) **не хранятся** — считаются из операций.
- Экраны не пишут в базу напрямую — только через `db/actions.ts`.
- Навигация через `#/адрес` — работает на GitHub Pages и в Capacitor без настройки сервера.
- `base: './'` в `vite.config.ts` — относительные пути, готово к упаковке в APK (Capacitor).
